# 学习者使用指南 · 基础巩固 15 分钟循环

> 写给学习者本人（也写给喂料者）。核心原则只有一条：
> **这个阶段不需要更多内容，需要的是把已有内容反复"说"和"听"出来。**
> 工具里的一切功能，都是为这个循环服务的。

## 一、每天 15 分钟，四步循环（顺序固定）

### 第 1 步 · 复习旧词（2 分钟）— 词汇卡 → 打开「复习模式」
- 只做**到期的词**（工具按你的记忆排期自动筛选，今天没有到期就 🎉 关掉）。
- 看西语 → 心里先想中文 → 点卡翻面确认 → 诚实点「记得 ✓」或「忘了 ✗」。
- **忘了不丢人，点「忘了」正是记忆在干活**——它会很快再来找你。

### 第 2 步 · 磨耳朵（5 分钟）— 听辨
- 只选**你最弱的那一类**音素，反复做：先 b/v，攻克了再换 l/r、r/rr、元音、重音。
- 标准：一类连续两天全对，才换下一类。不要每天换着玩。

### 第 3 步 · 开口（5 分钟）— 跟读 + 评分（本循环的核心，不许跳过）
- 选 2~3 句，流程：听常速 → 听慢速 → **开口跟读录音** → 回放自己的录音对比 → 🎯 评分。
- 评分 ≥80% 算过关；<80% 就重录一次，别超过 3 次（第 3 次仍不行，说明这句太难，换一句，明天再来）。
- **这一步就是"真诚互动"**：你必须出声，工具才听得见你、才给反馈。默读不算练习。

### 第 4 步 · 听写（3 分钟）— 检验耳朵
- 听 1~2 句：先慢速听写，全对再升常速。
- 听写是听力最诚实的镜子——"以为听懂"和"真听清了"在这里现出原形。

### （周末 5 分钟）Anki 卡组
- 让喂料者跑 `node scripts/export-anki.mjs --all`，导入 Anki 后按它的排期复习即可。与内置 SRS 二选一，别两套都背。

## 二、三条纪律（比任何功能都重要）

1. **巩固旧 > 学新**：新课内容只是"原料"，循环才产生能力。每周新课 ≤ 1 课。
2. **出声 > 看**：能开口就不默读，能听就不看字幕（听写先不看原文）。
3. **少量高频 > 大量低频**：A1 阶段，`hola / gracias / ¿Cómo estás?` 背得滚瓜烂熟，胜过认识 200 个不常用的词。工具里的词汇都是高频词，反复循环即可。

## 三、什么时候算"基础巩固"完成？

- 听辨：b/v、p/b、t/d、l/r、r/rr、元音、重音 七类全部连续两天全对；
- 跟读：任意 5 句连续评分 ≥80%；
- 词汇：SRS 里 90% 的词达到"记得"且间隔 ≥7 天。

达成后，就可以进入下一阶段（真实对话 / 更多内容），到时候工具再升级也不迟。

## 四、给喂料者的配套动作（每周 10 分钟）

1. 拍教材/课件 → `node scripts/ocr.mjs 照片.png --out 课.txt --to-source` → 校对 → 存为 `data/raw/<课程>/source.md`；
2. `node scripts/build-pack.mjs --all && node scripts/generate-audio.mjs --all`；
3. 告诉学习者：本周新增哪一课、听辨主攻哪个音素（别告诉她"全都要练"）。

## 补充：新增功能（2026-08-16 起）

- **课文包**：练习页课程列表里有「现代西语」系列（第 1-7 课 + 课文对话），内容与课堂教材同步，优先练这些。
- **📊 报告页**：第四个页签「报告」——看连续打卡天数、今日练习量、到期复习卡、近 8 周热力图。数据自动同步云端，换设备不丢。
- **添加到主屏幕**（iPhone）：Safari 打开 → 分享 → 添加到主屏幕 → 以后从桌面图标进入，全屏无地址栏，体验像 App。
- **离线也能练**：断网时进度先记本机，联网后自动同步到云端。
