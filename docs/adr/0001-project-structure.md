# ADR-0001：项目结构、技术栈与数据流水线

- 状态：**已采纳**（2025-08-14）
- 背景：从零搭建"西班牙语陪练"，需要长期多人（人 + DeepSeek + Codex）协作，要求架构友好、可被任何 AI 快速接手。

## 决策

1. **纯文本数据 + 单向流水线**
   `data/raw/*.md`（唯一人工编辑入口）→ `scripts/build-pack.mjs` → `data/packs/*.json` → `scripts/generate-audio.mjs` → 音频 → 练习页读取。产物一律脚本生成，人工不手改。

2. **技术栈：零 npm 依赖**
   - 脚本：Node.js ≥ 18 标准库（child_process、fs、http、path）。
   - 前端：纯 HTML/CSS/JS，无框架、无构建步骤。
   - 理由：依赖越少，越不容易烂；任何 AI 接手时不用装环境；部署 = 拷贝文件夹。

3. **音频：macOS 内置 `say`，输出 m4a/AAC**
   - 语音 Mónica（es_ES），可选 Paulina（es_MX）。
   - 理由：零成本、离线、质量可接受；浏览器原生支持 AAC。
   - 可替换性：TTS 引擎封装在单个脚本内，pack 结构不感知引擎差异。

4. **练习页：静态 Web 应用，局域网访问**
   - `scripts/serve.mjs` 提供静态服务；手机与电脑同 Wi-Fi 即可用。
   - 跟读录音在浏览器本地完成（MediaRecorder），不上传服务器。

5. **文档先行**
   - `docs/design.md` 产品设计；`docs/adr/` 决策记录；`docs/progress.md` 进度日志。
   - 理由：Codex 或其他 AI 随时可接手，不用口头交接。

## 后果

- 优点：环境零安装、可验证、可回滚（产物可重新生成）、协作门槛极低。
- 代价：功能丰富度受限（无数据库、无用户系统）——对单用户家庭场景完全够用；将来需要在线部署时，数据格式与流水线可原样保留。
