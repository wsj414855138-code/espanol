# 发音评测 API 调研与方案评估（供决策）

> 2025-08-14 · 调研人：DeepSeek（项目内协作）
> 背景：练习页"跟读评分"目前用浏览器 Web Speech API（免费、零成本），但 iPhone 的 Safari/Chrome 不支持 SpeechRecognition，且反馈只有"词命中率"这种粗粒度。目标：找**支持西语**、**音素级反馈**、性价比好的评测 API。
> 决策原则（用户明确）：不以省钱为目标，综合效果与性价比。

## 一、结论先行

| 结论 | 说明 |
|---|---|
| **当前唯一明确支持西语发音评测的候选：SpeechSuper（驰声）** | 官方语言清单 8 种含 Spanish，功能最全（音素级错误诊断） |
| 国内大厂（讯飞/腾讯/百度/阿里/火山）的发音评测**均未公开支持西语** | 讯飞官方文档明确只支持中文+英文；其余以 K12 中英场景为主 |
| 建议路径：**先用 Web Speech 免费版跑通体验 → 决定升级时申请 SpeechSuper** | 接入成本低（官方 Node demo 现成），不阻塞现在的基础巩固 |

## 二、逐个评测

### 1. SpeechSuper（驰声，苏州，海外品牌 speechsuper.com）
- **支持语种**：8 种——英、中、德、法、俄、韩、日、**西班牙语**（[官方 README](https://github.com/speechsuper/SpeechSuper-API-Samples) 明示）
- **功能**（西语可用性以开通后实测为准，README 描述）：
  - 音素/音节/词/句四级评分；流利度、完整度、节奏/语速
  - **音素级错误诊断**（增读/漏读/替换——"哪个音不对"）、重音分析、连读检测、句尾升降调
  - 有"自由口语评测"（Unscripted：语法/词汇维度，README 中为英文版，西语需确认）
- **接入**：HTTP + WebSocket；官方多语言示例（Node/Python/Java/Swift…）；音频建议 16kHz/16bit/mono，支持 wav/mp3/opus/ogg/amr
- **申请方式**：官网 "Contact us" 表单 → **销售跟进**（非自助注册；商务定价，按量或套餐，价格未公开）——申请需要留联系方式，会有销售对接
- **适配我们的工程**：前端录音（webm/opus）→ 服务端转 wav 或直传 opus → 调 API → 展示音素级反馈。需要一个小服务端（我们目前是纯静态，会新增一个评分代理脚本）
- **风险点**：价格未公开需询价；西语引擎质量需拿样本实测

### 2. 科大讯飞（语音评测，流式版）
- 官方文档明确："语言种类：**中文、英文**"（[ISE 文档](https://shandong.xfyun.cn/doc/Ise/IseAPI.html)）——**无西语** ❌
- 功能是行业标杆（音素级、题型丰富），但对本项目无意义

### 3. 腾讯云（智聆口语评测 SOE，新版）
- 官网未公开西语支持；产品定位 K12 中英口语考试（[产品概述](https://cloud.tencent.cn/document/product/1774/107335)、[计费](https://cloud.tencent.cn/document/product/1774/107342)）
- 需开通后自行确认语种，**公开信息不支持西语** ❌（除非实测打脸）

### 4. 百度智能云 / 阿里云 / 火山引擎
- 百度：语音评测产品面向中英（教育评测），未见西语；阿里云：智能语音交互 ISI 以 ASR/TTS 为主，**无独立发音评测产品线**；火山引擎：TTS/ASR 强（CosyVoice、[TTS 评测](https://www.volcengine.com/docs/6359/162419)），未见教育发音评测 API
- 三家均**未发现西语发音评测公开产品** ⚠️

### 5. 有道智云
- 有"实时语音评测"，宣传支持 44 种语言（可能含识别/翻译维度）；发音评测（朗读评分）语种需注册实测，**西语未见明确背书** ⚠️

### 6. 国际备选（超出用户要求的国内范围，供参照）
- **Azure Speech Pronunciation Assessment**：明确支持多语种含西班牙语，音素级、错误诊断，免费层 5 小时/月；英文文档；接国内网络可能需国际账号与支付方式
- **Speechace**：专注发音评测（多语种含西语），按量计费、可在线试用 demo，文档清晰
- 这两家效果公认不错，但支付与网络便利性不如国内方案

## 三、推荐方案（供拍板）

**阶段一（现在，零成本）**：保持 Web Speech 免费评分，手机端标注"评分需 Chrome/Edge 桌面版"，不影响听辨/听写/复习。先跑 2~4 周基础巩固。
**阶段二（升级）**：申请 **SpeechSuper**（中文团队、中文沟通、8 语言含西语、音素级诊断正中"哪个音不对"需求）——你填官网 Contact us 表单，销售跟进报价（先问：西语引擎是否生产级、有无免费试用额度、按量单价）。
> 如果 SpeechSuper 询价不满意或西语实测效果差，备选 **Azure**（效果强但英文文档/国际支付）或 **Speechace**。
