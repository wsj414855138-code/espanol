> 课文主题：我的全家福（家庭成员与年龄）

## 词汇

| 西语 | 中文 | 例句（西语） | 例句（中文） |
|---|---|---|---|
| foto | 照片 | Esta es la foto de mi familia. | 这是我们家的照片。 |
| abuelo / abuela | 祖父 / 祖母 | Mi abuelo es mayor. | 我祖父年纪大了。 |
| mujer | 女人，妻子 | La mujer rubia es mi madre. | 那位金发女士是我妈妈。 |
| mayor | 年长的 | Son muy mayores. | 他们年纪很大了。 |
| blusa | 女式衬衫 | Lleva una blusa roja. | 她穿一件红色衬衫。 |
| veinticinco | 二十五 | Tiene veinticinco años. | 她二十五岁。 |
| cincuenta | 五十 | Tiene cincuenta años. | 他五十岁。 |
| ochenta | 八十 | Tienen ochenta años. | 他们八十岁。 |

## 听辨

| 类别 | 词A | 词B | 中文说明 |
|---|---|---|---|
| 元音 | rubio | rubia | 金发的（阳性 / 阴性） |
| 元音 | limpio | limpia | 干净的（阳性 / 阴性） |
| 元音 | alto | alta | 高的（阳性 / 阴性） |
| 重音 | cuánto | cuanto | 多少 / 多么（关系） |
| t/d | tos | dos | 咳嗽 / 二 |
| p/b | peso | beso | 重量 / 亲吻 |
| l/r | lana | rana | 羊毛 / 青蛙 |
| r/rr | caro | carro | 贵的 / 车 |

## 句型

| 西语 | 中文 |
|---|---|
| Esta es la foto de mi familia. Somos siete. | 这是我们家的照片。我们家有七口人。 |
| Estamos en la habitación de mi hermana. | 我们在姐姐的房间里。 |
| La habitación está limpia y ordenada. | 房间干净又整齐。 |
| Mi hermana es cantante. Tiene veinticinco años. | 我姐姐是歌手。她二十五岁。 |
| El hombre moreno es mi padre. Es taxista. | 那位皮肤黝黑的男人是我爸爸。他是出租车司机。 |
| Es alto, fuerte y alegre. | 他个子高、身体强壮又开朗。 |
| La mujer rubia y de blusa roja es mi madre. | 那位金发、穿红衬衫的女士是我妈妈。 |
| Es peluquera. Tiene también cincuenta años. | 她是理发师。她也五十岁。 |
| ¿Cuántos sois en tu familia? — Somos siete. | 你家有几口人？——七口。 |
| ¿Cuántos hermanos tienes? — Tengo dos hermanos. | 你有几个兄弟姐妹？——我有两个兄弟。 |
| ¿Cómo está la habitación de tu hermana? — Está limpia y ordenada. | 你姐姐的房间怎么样？——干净又整齐。 |
| ¿Son mayores tus abuelos? — Sí, tienen ochenta años. | 你祖父母年纪大吗？——是的，他们八十岁了。 |
