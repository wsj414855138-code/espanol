# A1 现代西语 第 1 课 课文：¿Quién es él?

> 课文对话：¿QUIÉN ES ÉL?（他是谁？）

## 词汇

| 西语 | 中文 | 例句（西语） | 例句（中文） |
|---|---|---|---|
| ¿quién? | 谁 | ¿Quién es él? | 他是谁？ |
| llamarse | 名叫 | Ella se llama Ana. | 她叫安娜。 |
| amigo / amiga | 朋友（男/女） | Paco y Pepe son amigos. | 帕科和佩佩是朋友。 |
| cubano / cubana | 古巴的 | Paco es cubano. | 帕科是古巴人。 |
| chileno / chilena | 智利的 | Pepe es chileno. | 佩佩是智利人。 |
| panameño / panameña | 巴拿马的 | Ana es panameña. | 安娜是巴拿马人。 |
| chino / china | 中国的 | Es china. | 她是中国人。 |
| ellos / ellas | 他们 / 她们 | Ellos son amigos. | 他们是朋友。 |

## 听辨

| 类别 | 词A | 词B | 中文说明 |
|---|---|---|---|
| 元音 | ella | olla | 她 / 锅 |
| 元音 | mi | mí | 我的 / 我（重读） |
| l/r | lana | rana | 羊毛 / 青蛙 |
| m/n | mi | ni | 我的 / 也不 |
| t/d | tú | dos | 你 / 二 |
| 重音 | este | está | 这个 / 他（她）在 |
| 重音 | quién | quien | 谁（疑问）/ 谁（关系代词） |
| 元音 | Ema | ama | 埃玛（人名）/ 爱（动词变位） |

## 句型

| 西语 | 中文 |
|---|---|
| ¿Quién es él? — Él es Pepe. | 他是谁？——他是佩佩。 |
| ¿Es Pepe chino? — No, Pepe no es chino. Pepe es chileno. | 佩佩是中国人吗？——不，佩佩不是中国人，佩佩是智利人。 |
| Ella se llama Ana. Ana es panameña. | 她叫安娜。安娜是巴拿马人。 |
| Ella es Li Xin. Es china. | 她是李欣。她是中国人。 |
| Paco y Pepe son amigos. | 帕科和佩佩是朋友。 |
| Ana y Li Xin son amigas. | 安娜和李欣是朋友。 |
| ¿Es él Paco? — Sí, él es Paco. | 他是帕科吗？——是的，他是帕科。 |
| ¿Es ella Ema? — No, ella no es Ema, es Ana. | 她是埃玛吗？——不，她不是埃玛，是安娜。 |
| ¿Son amigos Pepe y Paco? — Sí, ellos son amigos. | 佩佩和帕科是朋友吗？——是的，他们是朋友。 |
| ¿Quién es ella? — Ella es Ana. | 她是谁？——她是安娜。 |
