## 句型

| 西语 | 中文 |
|---|---|
| ¿De qué color es el hipopótamo? — Es gris. | 河马是什么颜色？——是灰色。 |
| ¿De qué color son los zapatos? — Son negros. | 鞋子是什么颜色？——是黑色。 |
| Los plátanos son amarillos. | 香蕉是黄色的。 |
| La bandera de España es roja y amarilla. | 西班牙国旗是红色和黄色的。 |
| El oso panda es blanco y negro. | 熊猫是黑白色的。 |
| Las flores tienen muchos colores. | 花有很多种颜色。 |
| Este es mi padre. Se llama Juan y tiene 47 años. | 这是我爸爸，他叫胡安，47 岁。 |
| ¿Cuántos hermanos tienes? — Tengo dos hermanos. | 你有几个兄弟姐妹？——我有两个。 |
| ¿Cómo se llaman? — Se llaman Paco y Pilar. | 他们叫什么名字？——他们叫帕科和皮拉尔。 |
| ¿Cuántos años tiene el tío Paco? — Tiene 52 años. | 帕科舅舅多少岁？——52 岁。 |
| ¿Está casado? — Sí, está casado con María y tienen dos hijos. | 他结婚了吗？——结了，他和玛丽亚结婚，有两个孩子。 |
| ¿Cómo se llaman tus padres? | 你的父母叫什么名字？ |
| Mamá, ¿cómo se llaman tus hermanos? | 妈妈，你的兄弟姐妹叫什么名字？ |
