## 词汇

| 西语 | 中文 | 例句（西语） | 例句（中文） |
|---|---|---|---|
| primero / después | 首先 / 然后 | Primero, estudio español. Después, hago deporte. | 我先学西语，然后做运动。 |
| por la mañana | 在早上（时段） | Tenemos la clase de español por la mañana. | 我们早上有西语课。 |
| por la tarde | 在下午（时段） | Hago deporte por la tarde. | 我下午做运动。 |
| por la noche | 在晚上（时段） | Juan ve la tele por la noche. | 胡安晚上看电视。 |
| el texto | 课文 | ¿Puedes comentar el texto en español? | 你能用西语评述课文吗？ |
| el artículo | 文章 | ¿Podéis escribir un artículo en español? | 你们能用西语写一篇文章吗？ |
| enfermo / enferma | 病了的 | ¿Estás enfermo? | 你病了吗？ |
| cansado / cansada | 疲惫的 | Juan está muy cansado. | 胡安很累。 |
| ocupado / ocupada | 忙碌的 | Mi marido está ocupado, no puedo hablar con él. | 我丈夫很忙，我不能跟他说话。 |
| contento / contenta | 高兴的 | Mis padres están contentos. | 我父母很高兴。 |
| tener que | 得（不得不） | Tengo que estudiar más. | 我得再多学习。 |
| hay que | 应该（无人称） | Hay que hacer deporte. | 应该做运动。 |
| la prisa | 着急，急事 | Tengo prisa. | 我赶时间。 |
| la película | 电影 | Veo películas el fin de semana. | 我周末看电影。 |
| las películas de terror | 恐怖片 | ¿Ves las películas de terror? — No, nunca veo. | 你看恐怖片吗？——我从来不看。 |
| la naranja | 橙子 | La naranja es naranja. | 橙子是橙色的。 |
| la manzana | 苹果 | Esta manzana es roja. | 这个苹果是红色的。 |
| la piña | 菠萝 | Quiero comer piña. | 我想吃菠萝。 |
| el mango | 芒果 | El mango es dulce. | 芒果很甜。 |
| la banana | 香蕉 | La banana es amarilla. | 香蕉是黄色的。 |
| la uva | 葡萄 | Como uvas por la tarde. | 我下午吃葡萄。 |
| el melocotón | 桃子 | Quiero un melocotón. | 我想要一个桃子。 |
| la sandía | 西瓜 | La sandía es grande. | 西瓜很大。 |
| la cereza | 樱桃 | Las cerezas son rojas. | 樱桃是红色的。 |
| la fresa | 草莓 | Quiero comer fresas. | 我想吃草莓。 |
| claro | 当然 | Claro que sí. | 那当然。 |
| para llevar | 打包带走 | ¿Comes aquí o para llevar? | 你在这儿吃还是打包？ |
| dar | 给 | ¿Me das un libro? | 你能给我一本书吗？ |
| abrir | 打开 | ¿Puedes abrir la puerta, por favor? | 请你开一下门好吗？ |
| esperar | 等待，希望 | Te espero un rato. | 我等你一会儿。 |

## 句型

| 西语 | 中文 |
|---|---|
| ¿Cómo te llamas? — Me llamo José. | 你叫什么名字？——我叫何塞。 |
| ¿Cuál es tu nombre? — Mi nombre es David. | 你叫什么名字？——我叫大卫。 |
| ¿Cómo se llama? — Se llama Cristina. | 他叫什么名字？——她叫克里斯蒂娜。 |
| ¿Cómo te apellidas? — Me apellido García. | 你姓什么？——我姓加西亚。 |
| ¿Cuál es tu apellido? — Mi apellido es Hernández. | 你的姓是什么？——我姓埃尔南德斯。 |
| Puedo bailar tango. | 我会跳探戈。 |
| ¿Puedes hablar más despacio? — Sí, puedo. | 你能说慢一点吗？——可以。 |
| Juan no puede contestar bien. | 胡安答得不好。 |
| Hay que estudiar. | 应该学习。 |
| Tienes que hacer deporte. Ya eres gordito. | 你得做运动了，你已经是小胖墩了。 |
| ¿Me amas, Lola? — Sí, Carlos, te amo. | 罗拉，你爱我吗？——爱，卡洛斯，我爱你。 |
| ¿Dónde están mis hermanos? — No los veo. | 我的兄弟们在哪儿？——我没看见他们。 |
| ¿Amas a Julia? — Sí, la amo. | 你爱胡莉亚吗？——爱，我爱她。 |
| ¿Por qué estudias español? — Quiero estudiar español para leer en español. | 你为什么学西语？——我想学西语，为了能用西语阅读。 |
| Quiero estudiar español porque mi novia es colombiana. | 我学西语，因为我女朋友是哥伦比亚人。 |
| ¿De dónde vienes? — Vengo de China. | 你从哪儿来？——我从中国来。 |
| Esta chaqueta no es mía. ¿Es tuya, Julia? | 这件外套不是我的。是你的吗，胡莉亚？ |
| ¿De quién es este libro? — Es mío. | 这本书是谁的？——是我的。 |
| Mi padre habla dos idiomas. — Pues el mío habla cuatro. | 我爸爸会说两种语言。——我爸爸会说四种。 |
| ¿Quieres conocer la ciudad? | 你想了解这座城市吗？ |
| ¿Me puedes dar unas llaves de la casa? | 你能把家里的钥匙给我吗？ |
